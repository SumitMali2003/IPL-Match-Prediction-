# IPL Match Prediction

### BDA Course Project

This is a **Big Data Analytics (BDA)** course project based on IPL match data.

The project uses **PySpark** to analyze IPL matches and build a simple machine learning model to predict the match winner.

## Tech Used

- Python
- PySpark
- Spark MLlib
- Jupyter Notebook / Google Colab

## What the Project Does

- Loads and explores IPL match data
- Analyzes seasons, teams, wins and venues
- Prepares data for machine learning
- Uses `StringIndexer` and `VectorAssembler`
- Builds a **Logistic Regression** model
- Predicts the possible match winner based on teams and toss winner
